# 🚀 Projetos em destaque

## 🛒 SistemaLoja PDV

Sistema de **Ponto de Venda desenvolvido em Python e integrado ao Microsoft SQL Server**.

O sistema permite controlar vendas, produtos, estoque e movimentações de caixa.

### Principais funcionalidades

- Cadastro e edição de produtos
- Controle de estoque
- Registro de vendas
- Abertura e fechamento de caixa
- Diferentes formas de pagamento
- Cálculo automático de troco
- Histórico e cancelamento de vendas
- Relatórios operacionais
- Integração com Dashboard Web

**Tecnologias:**  
Python · SQL Server · SQL · Tkinter · PyODBC

🔗 [Ver projeto no GitHub](https://github.com/gabrielnasc17/sistemaloja-pdv)

---

## 📊 SistemaLoja Dashboard

Dashboard Web desenvolvido para análise dos dados gerados pelo **SistemaLoja PDV**.

Os dados registrados pelo PDV são armazenados no SQL Server e disponibilizados ao dashboard através de uma **API desenvolvida em Python e Flask**.

### Indicadores disponíveis

- Faturamento
- Quantidade de vendas
- Ticket médio
- Produtos mais vendidos
- Formas de pagamento
- Estoque baixo
- Evolução das vendas por período

O dashboard também possui filtros interativos para análise dos dados.

**Tecnologias:**  
Python · Flask · SQL Server · API · Google Apps Script · JavaScript · Chart.js

🔗 [Ver projeto no GitHub](https://github.com/gabrielnasc17/sistemaloja-dashboard)

## 📦 Controle de TID e Caixa

Sistema web desenvolvido para **controle, validação e rastreabilidade de TIDs e caixas** durante etapas de entrada, conferência e saída.

O projeto foi desenvolvido com foco na automação de processos operacionais e redução de controles manuais.

### Principais funcionalidades

- Controle de TIDs e etiquetas
- Check-in de caixas
- Check-out de caixas
- Validação de TIDs
- Controle de itens pendentes
- Associação entre TID, etiqueta e caixa
- Validação de Asset Tracking
- Bloqueio de inconsistências
- Registro de usuário e data/hora
- Exportação de dados para CSV

**Tecnologias:**  
Google Apps Script · JavaScript · HTML · CSS · Google Sheets

🔗 [Ver projeto no GitHub](https://github.com/gabrielnasc17/controle-tid-caixa)
